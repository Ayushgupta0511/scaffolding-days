# 🏗️ scaffolding-days

> *Every great structure starts with scaffolding.*

This is my personal web development journey — documented one commit at a time.
From writing my first `<div>` to building full projects, this repo holds every line of code I've written while learning the web.

---

## 👨‍💻 About This Repo

This isn't a polished portfolio. It's a raw, honest record of learning.
You'll find messy experiments, half-finished ideas, gradual improvements, and occasional breakthroughs — all of it real.

---

## 📁 Structure

```
scaffolding-days/
│
```
